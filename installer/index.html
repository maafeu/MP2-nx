Create the package

The zip holds the port and your game's files as they are on the disc. It downloads while it is written.

Copy it to the Switch

  1. If you have an older version, delete its switch// folder first, so no file of another release is left there.
  2. Extract the zip to the root of the SD card: it makes switch//.
